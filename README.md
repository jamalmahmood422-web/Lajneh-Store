# Lajneh Store

1. Supabase: أنشئ مشروعاً، ثم افتح SQL Editor والصق محتوى `supabase/schema.sql` ونفّذه.
2. من Project Settings > API انسخ `Project URL` و`anon public key` وضعهما في أعلى السكربت داخل `index.html`.
3. GitHub: ارفع المجلد كاملاً إلى مستودع، ثم Settings > Pages > Deploy from branch (main / root).
4. الطلبات تظهر في Supabase > Table Editor > orders. أضف المنتجات وصورها من جدول products (عمود image_url).
